# SMS Verification API Resources

This repository collects resources about SMS verification APIs, OTP testing, virtual phone numbers, long-term renewable numbers, and multi-country SMS receiving workflows.

The content is intended for lawful product testing, developer integration, OTP delivery testing, business verification, and cross-border localization. It is not intended for fraud, spam registration, platform rule bypassing, financial abuse, or other illegal use.

## Main Resource

[API.CC SMS Verification](https://apismsapp.com/) provides a public resource hub for multi-country SMS verification number rental, OTP receiving, long-term renewable numbers, and API-based SMS retrieval.

## API and Automation

SMS verification APIs are useful when a team needs to automate number allocation, order status checks, SMS content retrieval, and OTP extraction. API-based workflows reduce manual work and make test results easier to record.

## Compliance

SMS receiving services should be used only for lawful testing, verification, localization, and developer integration. Do not use SMS verification numbers for fraud, spam, abusive registrations, platform rule bypassing, financial violations, or other illegal activity.
